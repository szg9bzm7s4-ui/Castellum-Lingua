# Grille de qualité des contenus

À appliquer à chaque unité, dans chaque langue, avant de la présenter comme « intégrée ». Une unité ne passe que si tous les critères bloquants (🔴) sont validés.

## A. Langue

| # | Critère | Bloquant | Comment vérifier |
|---|---|---|---|
| A1 | Chaque phrase est correcte et naturelle pour un locuteur natif. | 🔴 | Relecture par un locuteur natif ; noter son nom ou son rôle dans le suivi, sans le publier sans accord. |
| A2 | La traduction rend le sens et le registre (tu / vous, poli / familier). | 🔴 | Relecture bilingue. |
| A3 | Le registre est indiqué : standard, familier, régional, dialectal, vulgaire. | 🔴 | Champ `reg` renseigné. |
| A4 | La langue standard et le dialecte sont distingués (ex. italien de Naples / napolitain). | 🔴 | Étiquettes visibles dans l'appli. |
| A5 | Aucun contenu vulgaire sans étiquette et sans avertissement. | 🔴 | Recherche dans les données. |
| A6 | Les exemples sont réalistes (prix, lieux, noms, situations). | | Relecture. |

## B. Pédagogie

| # | Critère | Bloquant | Comment vérifier |
|---|---|---|---|
| B1 | Les mots sont introduits dans une situation utile, pas en liste isolée. | 🔴 | Chaque unité a au moins un dialogue ou une scène. |
| B2 | Chaque élément est réutilisé dans au moins deux contextes. | | Comptage automatique. |
| B3 | L'unité vise un objectif concret formulé en « Je sais… ». | 🔴 | Champ `can`. |
| B4 | Au moins deux exercices de production sans choix multiple par leçon. | 🔴 | Test automatique (variété). |
| B5 | Pas plus de deux exercices du même type d'affilée. | 🔴 | Test automatique. |
| B6 | Chaque erreur reçoit une explication précise et bienveillante. | 🔴 | Ligne « Pourquoi ? » présente. |
| B7 | Les variantes correctes sont acceptées ; les petites fautes sont tolérées si l'objectif est la communication. | | Liste de variantes testée. |
| B8 | Les éléments appris entrent en révision différée. | 🔴 | Présence dans la répétition espacée. |
| B9 | L'oral est facultatif et a une alternative écrite. | 🔴 | Test du parcours sans micro. |

## C. Exercices

| # | Critère | Bloquant | Mesure automatique |
|---|---|---|---|
| C1 | Une seule réponse acceptable parmi les choix. | 🔴 | Taux de QCM ambigus = 0. |
| C2 | Impossible de répondre par simple élimination. | | Moins de 5 %. |
| C3 | Distracteurs du niveau de l'apprenant. | | Part hors niveau à réduire. |
| C4 | Consignes traduites dans toutes les langues d'interface. | 🔴 | 0 consigne non traduite. |

## D. Audio

| # | Critère | Bloquant |
|---|---|---|
| D1 | Les phrases des premières leçons ont un fichier audio intégré (natif de préférence). | 🔴 pour une langue mise en avant |
| D2 | La source de l'audio est indiquée (intégré, en ligne, appareil). | 🔴 |
| D3 | La transcription reste visible si l'audio manque. | 🔴 |

## E. Honnêteté

| # | Critère | Bloquant |
|---|---|---|
| E1 | La couverture affichée correspond aux données (niveaux intégrés, audio). | 🔴 |
| E2 | Aucun niveau CECRL déduit du seul nombre de mots ou d'XP. | 🔴 |
| E3 | Aucune validation, certification ou témoignage inventés. | 🔴 |
| E4 | Les contenus générés automatiquement sont signalés comme non relus. | 🔴 |
